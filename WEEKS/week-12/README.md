# Week 12 — Review, Tools and AI-assisted V&V

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

ดำเนิน walkthrough/inspection แบบมีโครงสร้าง เลือก tool ให้สัมพันธ์กับงาน และบันทึก prompt/output/verification ของ AI อย่างรับผิดชอบ

## Input ที่ควรเตรียม

- Artifact จริงที่จะ review และ review objective
- Candidate tools, constraints, privacy/license considerations
- Evidence gaps จากสัปดาห์ก่อน

## Output ที่คาดไว้

`Review Record` และ `Tool Selection Rationale`
