# Week 15 — Problem Analysis and Test Reporting

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

เขียน defect report ที่ทำซ้ำได้ วิเคราะห์ปัญหา และสรุปผล/ความเสี่ยงคงเหลือให้เหมาะกับ stakeholder และการตัดสินใจ

## Input ที่ควรเตรียม

- Executed test evidence, defect/retest records และ metrics
- open risks, limitations และ release decision context
- audience/stakeholder information

## Output ที่คาดไว้

`Test Summary Report draft`
