# Week 07 — System Testing and UAT

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

สร้าง user journey, system scenario และ acceptance test ที่สะท้อนเป้าหมายผู้ใช้ พร้อมสื่อสารเงื่อนไขการยอมรับและเกณฑ์ผ่าน–ไม่ผ่าน

## Input ที่ควรเตรียม

- Requirements/Acceptance Criteria และ RTM
- stakeholder/user context และ critical journey
- system scope, environment และ integration assumptions

## Output ที่คาดไว้

`System/UAT Scenarios` — ชื่อไฟล์ path และ template จะประกาศพร้อมเอกสาร Week 07
