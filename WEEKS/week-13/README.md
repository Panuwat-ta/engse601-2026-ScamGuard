# Week 13 — Test Planning and Estimation

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

จัดทำ Test Plan ให้สอดคล้องกับข้อกำหนด ความเสี่ยง และข้อจำกัด โดยกำหนด scope, strategy, roles, schedule, entry/exit criteria, tools และ effort estimate

## Input ที่ควรเตรียม

- RTM, test designs/data/NFR outline
- ENGSE212 milestone, people, environment และ constraints
- remaining risks/open issues

## Output ที่คาดไว้

`Test Plan v1` สำหรับ Senior Project/ENGSE212
