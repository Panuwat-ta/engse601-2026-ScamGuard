# Week 14 — Monitoring, Control and Defect Management

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

ติดตามความก้าวหน้า จัดการ defect lifecycle, severity, priority และ triage พร้อมตีความ metrics/dashboard เพื่อเสนอการควบคุมงาน

## Input ที่ควรเตรียม

- Test Plan, executed evidence และ defect records ที่เกิดขึ้นจริง
- build/environment reference และ retest history
- agreed metrics/threshold

## Output ที่คาดไว้

`Defect Report / Metric Snapshot` — ต้อง trace ไปยังการรันจริง; ถ้ายังไม่รันให้ระบุ `Not Executed`
