# Week 11 — Non-functional Testing

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

แปลง Non-functional Requirements ให้เป็นเกณฑ์วัดได้สำหรับ performance, security, usability, compatibility และ reliability แล้วจัดลำดับตาม risk/บริบท

## Input ที่ควรเตรียม

- NFR/quality risks และ stakeholder expectations
- architecture/environment constraints
- metrics/threshold ที่มี source หรือ decision owner

## Output ที่คาดไว้

`NFR Test Outline` — ห้ามสร้างผล performance/security เสมือนทดสอบแล้ว
