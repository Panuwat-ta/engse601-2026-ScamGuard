# Week 10 — Test Data Engineering

สถานะ: โครงสร้างเตรียมล่วงหน้า — template และรายละเอียดการส่งจะเพิ่มภายหลัง

## เป้าหมายตามแผน

วางแผนสร้าง ตรวจสอบ ปกป้อง และจัดการ test data โดยจำแนก valid/invalid/boundary และข้อมูลเชิงลับ รวมถึงตรวจข้อมูลที่ AI ช่วยเสนอ

## Input ที่ควรเตรียม

- Test Case Suite และ data constraints
- schema/validation rules โดยไม่ใส่ข้อมูลส่วนบุคคลจริง
- privacy/security constraints และ environment ที่ได้รับอนุญาต

## Output ที่คาดไว้

`Test Data Sheet` พร้อม AI validation record เมื่อเกี่ยวข้อง
